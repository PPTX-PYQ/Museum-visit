# Unity Virtual Exhibition Hall Scene Design

## Project Overview
This is an immersive virtual exhibition space developed with Unity. Visitors can move freely in the exhibition scene and interact with various scene‑based interactive elements.

I completed level layout planning, scene‑asset setup, UI interface design and all interactive logic by writing C# scripts.

## Main Responsibilities
- Scene layout and level‑space design
- UI system construction for exhibition interaction
- Development and iteration of C# interactive scripts

## Development Tools
- Unity 2022
- Visual Studio 2022 (C#)
